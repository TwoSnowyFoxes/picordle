Code to recreate the [New York Times' Wordle game](https://www.nytimes.com/games/wordle/index.html) in [PICO-8](https://www.lexaloffle.com/pico-8.php) & [Lua](https://www.lua.org/).

# Currently under development
This project is currently still under devleopment. While the basic functionalities behind Wordle are working, there is still much to improve on multiple fronts (e.g. code, UX, sound). 

See [the releases tab](https://github.com/TwoSnowyFoxes/picordle/releases) for the most recent versions & changes, or check [the To Do List](docs/TODO.md) to see what's on the roadmap.
